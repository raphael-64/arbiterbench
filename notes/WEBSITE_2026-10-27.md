# ArbiterBench website — 2026-10-27

Prepared on `codex/arbiterbench-website` for review before launch.

The public release at base commit is authoritative: 71 total cases, 36 public, 35 held out, eight main judges, plus a separate 25-item high-effort run. Some older internal orientation says 54 and some public methodology prose still mentions an earlier 78-item composition. The website follows current release aggregates and the published writeup, without changing research data.

The public/internal launch material and writeup were inspected. Only already-public records, figures, model logos, and branding are used. No held-out IDs, evidence, or private annotations enter the site.

Implementation and deployment are documented in `site/README.md`. Local review covered the desktop page and a 390px-wide mobile iframe, full/public splits, balanced/pooled metrics, open-weight filters, search, empty results, and deep-linking into a case outside the initial six. Repository checks run with Python 3.12; macOS's Python 3.9 differs at floating-point roundoff and cannot pass the existing byte-exact metric comparison.

The design was revised during review to remove status dots, decorative uppercase/numbered labels, placeholder model dots, and the large marketing headline. It uses the original writeup's fonts and actual logos.
