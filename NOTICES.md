# Upstream sources and attribution

ArbiterBench repackages public agent runs. Nothing upstream is relicensed by us; each source keeps its own terms, and this
release is for **non-commercial research use**. Counts are for the full set, held-out items included.

| source | items | upstream and terms | note |
|---|---|---|---|
| Terminal-Bench 2.0 leaderboard trajectories | 52 | tasks: terminal-bench-2 (Apache-2.0); runs: public leaderboard submissions | attribution to the task authors and each submitting team |
| OSWorld-Verified (Holo3 runs) | 7 | OSWorld (Apache-2.0); verified-trajectories dataset (MIT) | screenshots show third-party interfaces and are **not shipped**; each is replaced by a size-and-hash pointer |
| DTap | 5 | included with the maintainers' consent | research use |
| SWE-bench experiments | 4 | `SWE-bench/experiments`; rights sit with each submitter; included with consent | research use |
| ITBench trajectories | 2 | code Apache-2.0; trajectories CC BY-NC 4.0 | **non-commercial** |
| tau2-bench | 1 | MIT | attribution |

If you maintain one of these sources and want an item changed or removed, open an issue or write to raphael@heuristic.build.
